## Bait answer

*"Schema-enforced structured output means the model returns your input strings unchanged — compare with `===`."*

Week 1 disproved it: zod constrains **shape**, not bytes. Yahoo sent `Tebow’s Purity Ring` (U+2019); Opus wrote `Tebow's` (U+0027). Every downstream join was by raw name, so one invisible character made the eval report the team as simultaneously missing *and* invented, and gave it a 🆕 arrow every week. The fix is two-layered on purpose: `canonicalizeTeams()` snaps output back to the facts' bytes at the seam, and `teamKey()` handles data persisted *before* the fix (week-1 history in S3) — LLM output needs an identity key, and old data needs migration thinking even in a JSON-blob store.

Second bait: *"a digest that fails the quality gate should retry until it passes, or block for human approval."* The build caps at 2 generations and ships the second attempt regardless — each retry doubles the Opus cost, and a missed 7:00 Tuesday is a worse failure than an imperfect roast. The escalation is observability (`gate_pass: false` in CloudWatch + the runbook's "correct it in the chat by hand"), not a blocking human loop.

## What a teammate wouldn't know

1. **"Never do arithmetic" beats "never hallucinate" as a prompt rule.** Two of three dry-run gate failures were *correct* subtractions of real facts ("lost by 39"). Truth isn't the invariant — provenance is — so the prompt now says a number the model computed itself is a violation even when right. And the checker had to learn number words: "beat **five** other teams" sailed past a digits-only regex ("one" is deliberately unscanned — it's a pronoun, and 1 is always a legal rank).
2. **`console.error` on Lambda tags every line ERROR in CloudWatch.** Locally stderr is just "keep stdout clean for the digest text"; on Lambda it would drown the one signal that matters (a failed invocation). Hence the `progress = AWS_LAMBDA_FUNCTION_NAME ? console.info : console.error` switch in `run.ts` — the same line means different things in different runtimes.
3. **A tracked local cache is a landmine:** `data/digest-history.json` was rewritten by every `npm run digest` — mock rankings included — so it sat one `git add .` away from committing a dry-run mock as league history. Now gitignored, and for the same reason the system prompt derives league name and team count from the facts: the hard-coded "Monarch United / twelve friends" would have introduced a 14-team mock as the real league.
